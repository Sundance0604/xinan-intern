# 城市信用债曲线与批量 OFR 查询

## 启动

1. 安装 Node.js 18 或更新版本；已有 Codex 捆绑运行时也可直接使用。
2. 如需 DeepSeek 批量解析，将 **DeepSeek配置.example.md** 复制为 **DeepSeek配置.md**，填写自己的 API Key；已有本地配置无需重复创建。
3. 双击本文件夹中的 **启动批量查询.cmd**，保持启动窗口运行。
4. 浏览器打开 `http://127.0.0.1:8765/`。如端口被旧版服务占用，请关闭旧版启动窗口后重新启动。

直接双击“**双击打开.html**”可进行离线单券查询，但不能持久保存数据，也不能调用本机 DeepSeek 服务。CMD 为纯 ASCII 命令、Windows CRLF 换行；`batch-server.cjs` 是必要的英文启动入口，请勿单独移动。

## 收到别人给的新 HTML 后如何更新

1. 在已经运行的查询页面右上角点击 **导入数据 HTML**。
2. 选择对方提供的 HTML。无需修改或替换本项目的网页。
3. 核对预览中的来源文件、估值快照日、记录数和字段数。
4. 点击 **保存并使用**。单券查询、曲线、批量债券匹配和利差报告立即使用新数据。
5. 刷新页面或重新启动服务后，仍自动使用这份数据。

新 HTML 必须包含兼容的 `window.CREDIT_DATA = { ... }` JSON 数据，至少具备代码、名称、发行人、期限、估值、评级、省份、城市、品种等必要字段。字段排列可以不同，但列名、类型、日期和每行长度必须符合约定。不支持的结构会显示具体原因，不会替换当前数据。

导入只提取内嵌 JSON，不执行对方 HTML 中的脚本，不加载其中的资源或替换你的前端。单次 HTML 上限 100MB，最多 250,000 条记录。导入日期早于当前日期时会在预览中提示。

**持久保存位置**（第一次成功保存后自动创建）：

- `runtime/当前快照.json`：当前查询数据，以及导入 HTML 文件名和保存时间。
- `runtime/上一版快照.json`：再次更新时保留的上一份数据，供恢复使用。

两个文件仅存于本机，不发送给 DeepSeek。原始 HTML 不会被覆盖。保存采用临时文件和原子替换；校验失败保留旧数据。多个页面同时更新时，会阻止过期页面覆盖新版本。

如需手工恢复上一版：关闭服务，先备份“当前快照.json”，再将“上一版快照.json”复制为“当前快照.json”，重新启动。未保存过 HTML 时，默认使用网页自带的 2026-09-15 原始快照。

右上角原有 **导入 Excel** 功能继续保留，但仍仅在当前会话生效；刷新会恢复已保存的 HTML 数据，或未保存时恢复预置数据。直接打开文件时，“导入数据 HTML”也只能临时使用，界面会明确提示。

## 批量查询与利差 Excel

在页面顶部直接粘贴多条报价文本，核对报价日期，点击 **识别并批量查询**。页面生成债券标签，点击标签查看原有城市曲线及 OFR 比较。点击 **利差 Excel** 下载包含“利差结果、计算口径、输入原文”的报告，支持 Excel 筛选和排序。

利差 BP =（输入 OFR 收益率(%) − 同期限拟合收益率(%)）×100。

曲线与原单券功能相同：分箱分别取期限和中债估值收益率的中位数，节点间线性插值，不向拟合区间外推。省份和城市逐券取当前快照字段；评级、YY 区间、发行方式、债券品种、期限上限、分箱宽度、每箱最少样本、特殊条款排除和是否剔除标的，使用页面当前设置。

OFR 来自粘贴文本或手工修正；期限、估值和曲线样本来自当前快照。缺 OFR 时不会使用中债估值补报价。未匹配、多个匹配、日期不一致、缺报价、节点不足或超出区间的条目保留，利差留空并说明原因。行权、永续、延期期限和文本地域/期限与快照的差异会提示核对。

更新快照后，旧批量结果清空，粘贴文本保留。请核对新快照对应的实际报价日期后重新识别，避免混用不同日期的数据。

## DeepSeek 配置

用记事本编辑根目录的 **DeepSeek配置.md**，修改 JSON 中的 `apiKey` 和 `model`，保存后下一次解析立即生效。也可在页面 API 设置中临时覆盖密钥，或配置 `DEEPSEEK_API_KEY` / `DEEPSEEK_MODEL` 环境变量。

**批量查询解析规则.md** 是实际交给模型的规则，包含原始27条参考样例及 OFR、估值、报价量、行权期限、地域和缺失值的处理要求。该文件不应填写密钥。

解析时只发送规则和粘贴文本到 DeepSeek 官方接口，不发送本地数据库。导入 HTML 和持久保存不需要 DeepSeek。配置中的有效密钥不要随文件夹对外分享；密钥文件及运行数据已加入 Git 忽略规则。

## 项目文件

```text
城市信用债曲线_完整离线包/
├── 启动批量查询.cmd          用户启动入口
├── batch-server.cjs          CMD 调用的英文入口
├── 双击打开.html             基于 data 目录原始 HTML 的前端
├── DeepSeek配置.md           本机密钥和模型
├── DeepSeek配置.example.md   无密钥配置示例，首次使用时复制
├── 批量查询解析规则.md       LLM 解析提示词和参考样例
├── assets/                   批量查询、HTML 数据提取及更新界面
├── server/                   本机 API、持久保存及上一版备份
├── tests/                    回归测试及合成数据生成器
├── runtime/                  用户导入后生成的当前/上一版快照
├── 数据库/                   2026-09-15 原始 JSON、SQLite 和字段说明备份
├── 第三方许可/               原网页 SheetJS 许可
└── 文件校验.json             静态项目文件 SHA-256
```

“数据库”里的文件保留为原始备份，不随 HTML 导入而自动更新，也不是当前网页的动态数据源。`data/城市信用债曲线_完整离线包/双击打开.html` 原件保留不变，本项目只读取其内容作为实现基础。
