# 固定报表模板

版本：2026-10-27。根据用户统一格式后的10月23日三张输出表提取。模板只保留表头、公式、收益口径说明和样式，不含日期、债券名称、证券代码、交易金额、税费或历史业绩。

盈利表原参考文件的A14长说明在29磅行高中显示不全，空白模板仅将该行增高至110磅，保证说明完整可读；用户原文件不作改动。

| 模板 | 固定版式 | 每日填充内容 |
|---|---|---|
| `盈亏情况.xlsx` | 用户的字体、边框、列宽，右侧E2:E4、E6:E8、E10:E18汇总区域 | 同券加总后每券一行、日期、收益、交易量、票息和拆借成本 |
| `每日结算分类.xlsx` | 周一至周五两行分类，周标题与边框 | 当前周标题、当日代缴和撮合；历史周与本周已发生日从前日文件滚动 |
| `销售交易部当日盈利情况.xlsx` | 最新数据/前一日数据两页，A1/B1/C1日期位置、A14收益统计说明 | A1报告日、B1年末、C1年初，指标、税费、累计值及收益率 |

日常仍使用`../scripts/pnl_tables.py`，其`gen_xlsx`已接入`../scripts/template_reports.py`。不要再次用临时脚本从零重建表格，也不要用过去逐笔展示的格式覆盖同券汇总版式。

金额显示两位小数，百分比显示两位百分数；底层数值精度不变。盈亏表默认保留18行展示区，债券过多时扩展右侧最后一个合并区，并移动拆借行、更新求和公式。合并前的逐笔成本明细保存在当日`output/_support/`。

模板与前日数据分开管理：模板提供版式，前日分类表提供历史分类，前日盈利表提供累计。不要把模板的空白当作前日累计0。盈利表本年累计与收益率设有缺失数据提示。税费单位为万元，用户给出的系统贷方金额（元）须除以10000；未提供的税费沿用前日，命令行会提示核实。

以后需要更换样式时，先让用户确认新的三张表，将其放入同一参考目录，再运行：

```powershell
conda run -n pavane python scripts/capture_report_templates.py "用户确认的三张表所在目录"
```

该命令会覆盖这里的空白模板，不修改参考文件。更新后必须检查数据已清空、样式保留、三表勾稽、同券汇总和超出默认行数的情况。捕获工具按当前固定版式识别输入区域，若用户调整了指标位置或列结构，应先同步修改捕获工具和填充代码，不能仅替换模板文件。
